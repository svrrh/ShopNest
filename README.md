# ShopNest 🛒

A full-stack MERN e-commerce application built with React, Node.js, Express, MongoDB, and Tailwind CSS.

## 🚀 Features

- Product listing and product details
- User registration and login
- JWT authentication
- Protected routes
- Persistent shopping cart
- Checkout with mock payment flow
- Order creation and order tracking
- Stock validation and automatic stock reduction
- Admin order-status management
- Responsive UI with Tailwind CSS

## 🛠️ Tech Stack

### Frontend
- React
- React Router
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
